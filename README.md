# 아빠장부 설치 안내서

화물 운행과 받을 돈을 한눈에 보는 개인용 앱입니다.
앱스토어 없이, **링크 하나로 갤럭시에 설치**하는 방식(PWA)이에요.

- 앱을 처음 열면 **구글 계정으로 로그인**합니다. 같은 계정이면 어느 휴대폰에서 열어도 같은 장부가 보여요. (4단계 설정 필요)
- 기록은 **휴대폰과 클라우드에 함께 저장**됩니다. 한 번 로그인한 뒤에는 인터넷이 없어도 기록되고, 연결되면 자동으로 올라가요.
- 다른 분께는 **카톡으로 링크만 보내면** 똑같이 설치할 수 있어요. 기록은 사람마다 따로 저장되어 섞이지 않습니다.

전체 순서: **1. 준비 → 2. 인터넷에 올리기 → 3. 아버지 폰에 설치 → 4. 구글 로그인 켜기**
2번과 4번은 컴퓨터에서 하는 게 편합니다. 처음 한 번만 하면 됩니다.
4번을 하기 전에는 로그인 화면 없이 휴대폰에만 저장되는 상태로 동작합니다.

---

## 1. 준비

- 무료 **GitHub 계정** (앱 파일을 올려둘 곳) — https://github.com 에서 가입
- 이 묶음(zip)의 압축을 푼 **trucklog 폴더**

> 올라가는 것은 앱 화면 파일뿐이고, **운행 기록은 올라가지 않습니다.** 기록은 각자 휴대폰(과 각자 구글 계정)에만 저장돼요.

---

## 2. 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name에 `trucklog` 입력 → **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누름
4. 압축 푼 **trucklog 폴더 안의 파일과 icons 폴더를 전부** 끌어다 놓기
   (index.html, app.js, sw.js, manifest.webmanifest, firebase-config.js, README.md, icons 폴더)
5. 아래 **Commit changes** 누르기
6. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
7. Branch에서 **main** / **/(root)** 고르고 **Save**
8. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다.
   `https://2kwangchun-create.github.io/trucklog/`
   이 주소가 앱 주소예요. 메모해 두세요.

---

## 3. 아버지 갤럭시에 설치

1. 앱 주소를 카톡으로 아버지께 보내기
2. 아버지 폰에서 링크를 길게 눌러 **"다른 브라우저로 열기" → Chrome**
   (카톡 안 브라우저에서는 설치 메뉴가 안 나옵니다. 꼭 **크롬**에서 여세요.)
3. 크롬 오른쪽 위 **⋮** → **"앱 설치"** 또는 **"홈 화면에 추가"** → **설치**
4. 홈 화면에 빨간 트럭 아이콘 **아빠장부**가 생깁니다. 이제부터 이 아이콘으로 여시면 돼요.

설치한 뒤에는 인터넷이 없어도 열리고 기록도 됩니다.

### 다른 분께 공유할 때
같은 주소를 카톡으로 보내고 3번처럼 설치하면 됩니다. 각자 폰에 따로 저장되어 서로의 기록은 보이지 않아요.

---

## 4. 구글 로그인 켜기 (약 15분)

이 단계를 마치면 앱을 열 때 **구글 로그인 화면**이 먼저 나옵니다.
로그인하면 **휴대폰을 잃어버리거나 바꿔도 기록이 남고**, 같은 구글 계정으로 로그인한 **다른 폰(자녀분 폰)에서도 같은 장부를 볼 수** 있어요.

- 다른 분께 공유한 경우, 그분은 **자기 구글 계정**으로 로그인하면 자기 장부만 따로 보입니다.
- 현장에서 인터넷이 안 될 때를 위해 로그인 화면 아래에 "로그인 없이 이 휴대폰에만 저장"도 있어요. 나중에 로그인하면 그동안 적은 기록이 함께 올라갑니다.
- 한 휴대폰에서 **다른 계정으로 바꿔 로그인하면**, 그 휴대폰에 남아 있던 이전 계정 기록은 화면에서 비워집니다(이전 계정 클라우드에는 그대로 있어요).

무료 서비스인 Google **Firebase**를 씁니다. 개인 장부 정도의 양은 무료 한도 안에서 충분합니다.

### 4-1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인
2. **프로젝트 만들기** → 이름 `trucklog` → Google 애널리틱스는 **사용 안 함** → 만들기

### 4-2. 웹 앱 등록하고 설정값 붙여넣기
1. 프로젝트 첫 화면에서 **`</>` (웹)** 아이콘 누르기
2. 앱 닉네임 `운행장부` → **앱 등록** (Hosting 체크는 하지 않음)
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값들을 복사
4. GitHub 저장소에서 **firebase-config.js** 파일을 열고 연필(✏️) 아이콘으로 편집
5. 마지막 줄 `window.FIREBASE_CONFIG = null;` 을 아래처럼 바꾸기 (값은 복사한 것으로):

```js
window.FIREBASE_CONFIG = {
  apiKey: "복사한 값",
  authDomain: "trucklog-xxxx.firebaseapp.com",
  projectId: "trucklog-xxxx",
  storageBucket: "복사한 값",
  messagingSenderId: "복사한 값",
  appId: "복사한 값"
};
```
6. **Commit changes** 누르기

> 이 값은 공개되어도 괜찮은 값입니다. 다른 사람이 기록을 볼 수 없게 막는 건 아래 4-4 "보안 규칙"이 합니다.

### 4-3. 구글 로그인 켜기
1. Firebase 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**
2. **로그인 방법** 탭 → **Google** → **사용 설정** → 지원 이메일 고르기 → **저장**
3. **설정** 탭 → **승인된 도메인** → **도메인 추가** → `2kwangchun-create.github.io` 입력 → 추가

### 4-4. 데이터베이스 만들기 + 보안 규칙
1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 위치: **asia-northeast3 (서울)** → **프로덕션 모드로 시작** → 만들기
3. **규칙** 탭에서 내용을 전부 지우고 아래를 붙여넣은 뒤 **게시**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 각자 자기 구글 계정의 기록만 읽고 쓸 수 있음
    match /users/{uid}/trips/{tripId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

### 4-5. 앱에서 로그인
1. 아버지 폰에서 아빠장부를 **두 번** 열기 (새 설정을 받아오려면 한 번 더 열어야 해요)
2. 로그인 화면에서 **구글 계정으로 시작하기** → 아버지 구글 계정 선택
3. 달력이 나오면 끝입니다. 폰에 있던 기록이 있으면 자동으로 올라가요. **[설정]**에서 "클라우드와 맞춤"을 확인할 수 있어요.

자녀분 폰에서 같은 장부를 보려면: 앱을 설치하고 **아버지와 같은 구글 계정**으로 로그인하면 됩니다.

---

## 5. 백업 습관 (클라우드를 안 켰다면 꼭)

- 앱 **[설정] → 백업 파일 보내기** → 카톡 **"나와의 채팅"** 이나 **구글 드라이브**로 보내 두기
- 2주 넘게 백업을 안 하면 달력 화면 위에 알림이 뜹니다.
- 새 폰에서는 앱 설치 후 **[설정] → 백업 파일 불러오기** 로 그 파일을 고르면 기록이 돌아옵니다.
  (같은 기록은 더 최근에 고친 쪽으로 합쳐지고, 지금 기록은 지워지지 않아요.)

### 세무사에게 보낼 때
- **[장부] → 이 달 장부를 엑셀 파일로 보내기**, 또는 **[설정] → 전체 기록 엑셀 파일로 보내기**
- 엑셀, 구글 시트에서 바로 열리는 파일(.csv)이 만들어집니다.

---

## 6. 앱을 고치고 싶을 때

1. 파일을 고친 뒤 GitHub 저장소에 다시 올리기 (같은 이름으로 덮어쓰기)
2. **sw.js** 맨 위의 `const VERSION = '1.0.0';` 숫자를 하나 올리기 (예: `'1.0.1'`)
3. 아버지 폰에서 앱을 열면 시작 화면 동안 새 버전을 받아 바로 바뀝니다. 앱을 쓰는 중에 올렸다면 화면 위에 **"새 버전이 있어요 [지금 업데이트]"** 가 뜨고, 누르면 바뀌어요. 기록과 적던 내용은 그대로 유지돼요.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| "앱 설치" 메뉴가 안 보여요 | 카톡 안 브라우저가 아니라 **크롬**에서 열었는지 확인. 크롬 ⋮ → "홈 화면에 추가"를 찾아보세요. |
| 로그인 버튼이 안 보여요 | firebase-config.js를 고친 뒤 앱을 **두 번** 열었는지 확인. |
| "이 주소가 Firebase에 등록되지 않았어요" | 4-3의 **승인된 도메인**에 `2kwangchun-create.github.io` 를 추가하세요. |
| "클라우드 저장 권한이 없어요" | 4-4 **규칙**을 붙여넣고 **게시**를 눌렀는지 확인. |
| 전화번호를 눌러도 반응이 없어요 | 번호 옆 **[복사]** 를 누르고 전화 앱에 붙여넣으세요. 설치한 앱에서는 보통 바로 키패드로 넘어갑니다. |
| 크롬 방문 기록을 지웠더니 기록이 사라졌어요 | 크롬의 "사이트 데이터 삭제"는 앱 기록도 지웁니다. 클라우드를 켜 두거나 백업 파일을 만들어 두세요. |

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| index.html | 앱 화면 |
| app.js | 앱 동작 (기록 저장, 달력, 받을 돈, 장부, 백업, 클라우드) |
| firebase-config.js | 클라우드 저장 설정값 (기본은 꺼짐) |
| sw.js | 인터넷 없이도 열리게 해 주는 파일 |
| manifest.webmanifest | 앱 이름, 아이콘, 색 |
| icons/ | 앱 아이콘 |

나중에 꼭 설치 파일(APK) 형태가 필요해지면, 같은 파일로 만들 수 있습니다.
